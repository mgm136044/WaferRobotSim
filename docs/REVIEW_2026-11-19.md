# 검수 보고서 (2026-11-19)

대상: 실측 치수·가운데 레일 반영 버전. 검수 방법은 두 가지입니다.
- **독립 검수자:** 별도 에이전트가 원본 저장소를 읽기 전용으로 두고 사본에서 실행해 검토했습니다.
- **사용자 관점 점검:** 배포 사이트와 로컬에서 직접 조작해 확인했습니다.

## 2. 발견 사항과 조치
| 등급 | 내용 | 조치 |
|---|---|---|
| 중요 | 실물 로그의 0번 정렬 이동거리(약 44 mm)가 실측 치수로 가능한 최대값(19 mm)보다 큼. 문서 설명("붙였는지 몰라서")이 차이를 설명하지 못함 | 문서 정정. 검증에 "0번 정렬 이동거리" 항목을 추가하고 **⚠️ 확인 필요**로 표시. 팀에 시작 끝에 붙인 상태의 새 BASE_TRACE 로그 요청 |
| 중요 | 치수 검사 일부가 설정값을 되읽는 수준. 레일 제거 시험의 이동(97 mm)이 예전 레일 위치(±159 mm)에 못 미침 | 센서 위치는 선 감지 시각으로 측정하도록 변경. 검사마다 측정 방법을 표기. 레일 끔 시험을 435 mm까지 벗어나는 시나리오로 교체 |
| 경미 | 자동 종료가 좌우·회전 운동을 보지 않아, 돌고 있는 로봇을 22 s에 멈춤 | 감시값에 좌우 위치·회전각·엔코더 추가 |
| 경미 | 옴니(비구동) 바퀴의 옆방향 힘 상한이 일반 바퀴와 같음 | 상한도 같은 비율(5%)로 낮춤 |
| 경미 | 끝 벽 판정이 차체 회전(모서리)을 무시. 옆으로 벗어나도 알림 없음 | 네 모서리 기준으로 판정. 작업 영역(900 mm) 밖, 레일 끔 상태의 이탈은 경고로 알림(벽으로 막지는 않음) |
| 경미 | 버전 표시 없는 예전 설정이 알림 없이 버려짐 | 바뀐 항목을 화면에 안내(불러오기·가져오기 모두) |

| 경미 | 같은 실측값 270이 두 설정으로 나뉨 | 시작 위치를 `로봇 뒤끝 → 모터축 270` 하나에서 계산하고, 필요할 때만 `시작 간격`을 더함 |

## 3. 사용자 관점 점검 (배포 사이트·로컬)
- 원본 ZIP 실행: 결과가 CLI와 같습니다(MISSION_DONE 235.81 s, 정지 위치 10곳 동일). 콘솔 오류 0건.
- 설정 탭: 실측 항목과 출처 설명이 표시됩니다. 실행 전에 값을 바꾸면 3D 로봇이 바로 바뀝니다.
- 설정 내보내기·가져오기: 새 형식(버전 4)이 그대로 왕복됩니다. 예전 파일을 가져오면 형상 값만 바꾸고 안내합니다.
- 실측 비교 탭: 실물 로그를 붙여 넣으면 RMS 1.9 deg/s로 겹쳐 그립니다.
- 예외 설정:
  - 규정 경기장: 정상 완주
  - 레일 켬 + 좌우 3% 차이: 편차 1.14 mm
  - 레일 끔: 이탈 경고 표시
  - 뒷축 구동: 배치 경고 + 미션 미완료(예상대로)
  - 질량·바퀴 0: 기본값으로 계산하고 경고

## 4. 남은 확인 사항 (팀)
1. 시작 끝에 붙인 상태의 BASE_TRACE 실물 로그. 0번 정렬 이동거리 차이(약 24 mm)를 확인하는 데 필요합니다.
2. 로봇 전체 길이(또는 모터축 → 앞끝). 471 mm를 넘으면 0→4 정지 때 끝 벽에 닿습니다.
3. 가정값: 기어 1:2, 뒷바퀴 지름(표시용), 레일 틈새·강성, 구동축 하중 비율, 센서 좌우 위치.
